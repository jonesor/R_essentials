# Video scripts

One outline per chapter video. Talk from the outline; read out only the lines marked **Script**, so the wording matches the book.

Each video is 5 to 8 minutes. Record section by section and join them. Keep small typing slips and fix them on camera.

The folder name starts with `_` so Quarto does not render it into the book.

**Before every recording**

- Open RStudio by double-clicking `R_practice.Rproj`.
- Increase the zoom: Tools > Global Options > Appearance > Zoom 125% or more.
- Clear the Console (Ctrl+L) and the Environment (broom icon).
- Have the chapter open in a browser on a second screen.
